# projeto_pratica projeto de pratica profissional, e escolhemos fazer um medidor de qualidade de ar por meio de js e hmtl, segue aqui os principais comandos do git:
 | Comando                    | Para que serve                                     |
| -------------------------- | -------------------------------------------------- |
| `git init`                 | Cria um repositório Git na pasta                   |
| `git status`               | Mostra o que mudou no projeto                      |
| `git add .`                | Adiciona todas as alterações para o próximo commit |
| `git add arquivo.js`       | Adiciona apenas um arquivo                         |
| `git commit -m "mensagem"` | Salva uma versão do projeto                        |
| `git log`                  | Mostra o histórico de commits                      |
| `git push`                 | Envia seus commits para o GitHub                   |
| `git pull`                 | Baixa alterações do GitHub                         |
| `git clone URL`            | Copia um repositório do GitHub para seu PC         |
| `git branch`               | Mostra suas branches                               |
| `git switch nome`          | Troca de branch                                    |
| `git switch -c nome`       | Cria e já entra em uma nova branch                 |

prótotipo inicial do projeto dando inicio com um medidor de qualidade de ar
